## Overview

The Bluetooth Mini Bug is a completed engineering project developed in 2021 to explore electronic waste repurposing and Bluetooth audio technology.

The project reuses components from a discarded Bluetooth neckband, including its existing microphone, wireless circuitry, and battery. The hardware was reconfigured into a compact prototype and tested with a paired smartphone.

This project provided practical experience in electronics disassembly, component reuse, Bluetooth connectivity, hardware integration, and sustainable electronics practices.

## Problem Statement

Discarded electronic devices often contain functional components that can be recovered and reused. Repurposing suitable components from obsolete Bluetooth accessories provides a practical way to explore electronics reuse while reducing unnecessary electronic waste.

## Project Approach

The project focused on recovering and reusing existing hardware rather than developing a completely new electronic circuit.

- **Component recovery:** Reused hardware from a discarded Bluetooth neckband.
- **Wireless connectivity:** Used the existing Bluetooth circuitry for pairing with a smartphone.
- **Audio hardware:** Retained the integrated microphone and associated audio electronics.
- **Power system:** Reused the original battery.
- **Prototype integration:** Reconfigured the recovered components into a compact assembly.
